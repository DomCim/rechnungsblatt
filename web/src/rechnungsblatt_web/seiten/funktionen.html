Was Rechnungsblatt kann

Jede Seite hier beschreibt eine Sache, die die Anwendung tatsächlich tut — und nennt am Ende, was sie ausdrücklich nicht tut. Das zweite ist so wichtig wie das erste: Eine Rechnung, die beim Steuerprüfer Ihres Kunden durchfällt, richtet mehr Schaden an, als eine fehlende Funktion je könnte.
