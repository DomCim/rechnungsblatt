Zahlung · EPC069-12

Der Code, der die Überweisung ausfüllt

Ein kleines Quadrat unten auf der Rechnung. Ihr Kunde hält die Banking-App darauf, und Empfänger, IBAN, Betrag und Verwendungszweck stehen schon im Formular. Kein Abtippen, keine vertauschte Ziffer in der IBAN, keine Rückfrage, welche Rechnungsnummer gemeint war.

Was im Code steht

Der GiroCode folgt der Spezifikation EPC069-12 des European Payments Council — dasselbe Verfahren, das auf Spendenaufrufen und Vereinsbeiträgen klebt. Rechnungsblatt füllt ihn aus den Daten, die ohnehin auf dem Beleg stehen:

  • Ihr Name als Zahlungsempfänger und Ihre IBAN aus den Stammdaten, die BIC, falls hinterlegt.
  • Den Bruttobetrag der Rechnung.
  • Den Verwendungszweck — in der Regel die Rechnungsnummer, damit der Zahlungseingang zuzuordnen ist.

Die Spezifikation setzt Grenzen: Der Name darf 70 Zeichen lang sein, der Verwendungszweck 140, der Betrag muss zwischen 0,01 und 999.999.999,99 Euro liegen. Fällt der Betrag heraus, lässt Rechnungsblatt ihn weg — die App fragt dann danach, statt einen falschen Wert vorzuschlagen.

Gezeichnet, nicht eingefügt

Der Code wird als Vektorgrafik direkt auf das Blatt gezeichnet: schwarze Rechtecke, kein Rasterbild. Das ist kein Selbstzweck. Ein eingefügtes Bild brächte einen eigenen Farbraum mit und damit genau das Problem, das die Briefpapier-Normalisierung gerade beseitigt hat — die PDF/A-Zusage wäre dahin.

Nebenbei bleibt der Code bei jeder Vergrößerung scharf und lässt sich auch von einem mäßig gedruckten Blatt noch lesen.

Ein Schalter in der Gestaltung

Der GiroCode lässt sich an- und abschalten; er gilt dann für alle Belege. Voraussetzung ist eine gültige IBAN in den Stammdaten — die verlangt die §-14-Prüfung ohnehin, sonst entsteht die Rechnung nicht.

Was hier nicht passiert

  • Rechnungsblatt ist kein Zahlungsdienstleister. Der Code füllt ein Überweisungsformular vor, mehr nicht — es fließt kein Geld über Rechnungsblatt.
  • Es gibt keinen Zahlungsabgleich. Ob und wann Ihr Kunde bezahlt hat, erfährt Rechnungsblatt nicht; ein Mahnwesen gibt es nicht.
  • Nicht jede Banking-App erkennt jeden QR-Code gleich zuverlässig. Der Code ersetzt die Angabe von IBAN und Verwendungszweck im Klartext nicht — beide stehen weiterhin auf dem Beleg.
