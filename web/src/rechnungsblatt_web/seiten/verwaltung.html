Postausgang

Ohne diese Angaben verschickt Rechnungsblatt keine Bestätigungscodes und keine Rücksetz-Links — die Nachrichten landen dann nur im Protokoll. Das Passwort wird verschlüsselt abgelegt und nie wieder angezeigt.

Unterschrift (DKIM)

Ohne Unterschrift landet Post von einer eigenen Domain regelmäßig im Spam — ein Bestätigungscode im Spamordner ist so gut wie keiner. Die Domain muss zum Absender oben passen.

      Plausible zählt Seitenaufrufe ohne Cookies. Ohne Adresse wird gar kein
      Skript eingebunden. Läuft die Seite über HTTPS, muss auch Plausible
      über HTTPS erreichbar sein — sonst blockt der Browser.
